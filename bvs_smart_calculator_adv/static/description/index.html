Smart Calculator Adv

Advanced edition for the Odoo backend: press ` (backtick) to open the floating calculator, switch between Basic and Advanced layouts, use memory keys and brackets, and browse a timestamped history tape-all without leaving your current Odoo screen.


Key Features
  • Same instant ` shortcut as the base Smart Calculator.
  • Basic mode (compact grid) and Advanced mode (MC/MR/M+/M-, brackets, wider keypad).
  • Expression-style evaluation with guarded parsing and readable errors.
  • History tape with timestamps; recall a row with one click.
  • Draggable panel; hide with Esc or `; full close clears history when intended.

Upgrade path: install Smart Calculator Pro when you need the Biz rail (markup, margin, discount, tax, landed cost) layered on top of these modes.
Modes & memory
  • Segmented header switches Basic vs Adv without reloading Odoo routes.
  • Advanced grid exposes bracket hygiene indicators + undo-friendly deletes.
  • Memory keys behave like desk calculators buyers already trust.
History workflow
  • Timestamps contextualise each row when auditing quotes.
  • Tap-to-recall pushes values straight into the active expression.
  • History honours hide/show cycles thanks to container-owned arrays.
Deployment notes
  • Assets remove the base calculator bundle entries before injecting Adv templates.
  • No duplicate OWL roots-still one SmartCalculatorContainer registration.
  • Perfect middle tier between free base and finance-heavy Pro release.
Demo storyline for screenshots: (1) CSR quoting on a CRM form with Basic mode, (2) purchaser stacking parentheses + memory on a PO line using Advanced mode.
Odoo edition
Odoo 19 backend (web.assets_backend).
Dependencies
bvs_smart_calculator, web.
Installation path
Add the addons directory containing bvs_smart_calculator_adv, update Apps, install Adv-the base Smart Calculator module installs automatically.
