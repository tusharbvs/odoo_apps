Smart Calculator Advanced

Advanced edition for the Odoo backend: press ` (backtick) to open the floating calculator, switch between Basic and Advanced layouts, use memory keys and brackets, and browse a timestamped history tape-all without leaving your current Odoo screen.


Key Features
  • Same instant ` shortcut as the base Smart Calculator.
  • Basic mode (compact grid) and Advanced mode (MC/MR/M+/M-, brackets, wider keypad).
  • Expression-style evaluation with guarded parsing and readable errors.
  • History tape with timestamps; recall a row with one click.
  • Draggable panel; hide with Esc or `; full close clears history when intended.

Installation path
Add the addons directory containing bvs_smart_calculator_adv, update Apps, install Adv-the base Smart Calculator module installs automatically.
