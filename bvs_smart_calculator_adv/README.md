# Smart Calculator Adv (`bvs_smart_calculator_adv`)

Advanced floating calculator for the **Odoo 19** backend. Extends **Smart Calculator** with **Basic** and **Advanced** layouts, brackets, memory keys (MC / MR / M+ / M-), and a timestamped history tape.

**Author:** BitVoyage Solution · **Website:** [tusharwork89@gmail.com](mailto:tusharwork89@gmail.com)

## Features

- Same backtick shortcut as the base module
- Mode switcher: compact Basic grid vs Advanced keypad (memory + brackets)
- Expression evaluation with guarded parsing
- History with timestamps and one-click recall
- Asset bundle replaces base calculator assets (no duplicate templates)

## Dependencies

- `bvs_smart_calculator`
- `web`

## Installation

1. Ensure **Smart Calculator** (`bvs_smart_calculator`) is available on your addons path.
2. Install **Smart Calculator Adv** - Odoo will pull in the base module if needed.

## Suite

Install **Smart Calculator Pro** on top when you need the business rail (markup, margin, discount, tax, landed cost).
