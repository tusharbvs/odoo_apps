Gulf Cooperation Council - Invoice - Mulit-Branch setup

This module adds support for GCC dual-language invoicing support for multi-branch Odoo environments. It allows invoices to be generated in both Arabic and English, in line with Gulf Cooperation Council (GCC) invoicing requirements.


When GCC invoicing is enabled for the main company, the module applies the same configuration to all associated branches. This provides a centralized way to use dual-language invoicing across multiple branches without requiring separate configuration for each branch.
