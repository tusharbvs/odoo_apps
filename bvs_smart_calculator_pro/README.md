# Smart Calculator Pro (`bvs_smart_calculator_pro`)

Professional tier floating calculator for the **Odoo 19** backend. Builds on **Smart Calculator Adv** with an enhanced UI, a **Business** side rail (markup, margin, discount, tax, landed-style flows), and a registered JS service hook for tax-aware behaviour alongside **Accounting**.

**Author:** BitVoyage Solution · **Website:** [tusharwork89@gmail.com](mailto:tusharwork89@gmail.com)

## Features

- Everything from Adv (modes, memory, brackets, history)
- Integrated Biz strip after evaluation with expandable detail pane
- Shared drag target for calculator + business panel
- Service registration (`bvs_smart_calculator_tax`) for extensions

## Dependencies

- `bvs_smart_calculator_adv`
- `web`
- `account`

## Installation

1. Ensure **Smart Calculator** and **Smart Calculator Adv** are on your addons path (or install **Pro** and let Odoo resolve dependencies).
2. Install **Smart Calculator Pro**.
