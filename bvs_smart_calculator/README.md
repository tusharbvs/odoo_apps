# Smart Calculator (`bvs_smart_calculator`)

Keyboard-triggered floating calculator for the **Odoo 19** backend. Press the **backtick** key (<kbd>`</kbd>) from backend screens to open the panel, use mouse or keyboard, and keep working on the current form or list.

**Author:** BitVoyage Solution · **Website:** [tusharwork89@gmail.com](mailto:tusharwork89@gmail.com)

## Features

- Global backtick shortcut and **Esc** / backtick to hide
- Draggable floating panel
- History tape with recall
- Standard arithmetic with sensible error handling (e.g. division by zero)

## Dependencies

- `web`

## Installation

1. Add this repository path (or folder containing `bvs_smart_calculator`) to your Odoo **addons** path.
2. Update the Apps list and install **Smart Calculator**.

## Suite

This module is the base tier. **Smart Calculator Adv** and **Smart Calculator Pro** extend it with advanced modes and business tools.
